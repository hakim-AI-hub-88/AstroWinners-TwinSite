# TwinSite 30-second demo and judge walkthrough

0–05s: Future Moon/Mars missions need mission-specific terrestrial analog test sites. No one Earth site reproduces every condition.
05–12s: Select a real planetary target and a mission objective. Click Run. Show cited NASA acquisition and a phase progress excerpt.
12–19s: Show ranked Earth candidates, strengths/weaknesses, spatial/temporal scale and one rejected or unknown claim.
19–25s: Generate a complementary portfolio and alter a relevant mission weight to demonstrate deterministic change.
25–30s: Open read-only Data Explorer provenance + downloadable scientific report. TwinSite makes analog selection explainable and reproducible.

Do not narrate a feature not working in the live application. Have a longer 3-minute live judge demo with real-data evidence and one no-AI fallback. Pre-recorded footage must not conceal fabricated measurements.
