# TwinSite release gates

## G0 — contracts
- [ ] One repo, single canonical root, fixed schema versions and data meanings
- [ ] Exclusive file ownership, branch/worktree per lane
- [ ] No secrets in repo; AI models optional and no paid inference

## G1 — working end-to-end
- [ ] Mission creation returns ID, worker executes, progress updates ordered
- [ ] Deterministic score/portfolio/report generated from clearly labeled fixture
- [ ] Frontend navigates to actual result page, never fakes success

## G2 — scientific evidence
- [ ] Actual NASA Earth + Moon or Mars product files retrieved (not metadata only)
- [ ] Product/granule ID, source URL, raw hash, QA flags, units, CRS, time recorded
- [ ] Derived terrain statistics use defensible common physical scale
- [ ] Invalid/missing mandatory evidence blocks strict scientific claim

## G3 — feature completeness
- [ ] Real candidate pros/cons and uncertainties explained with source links
- [ ] Single- and multi-site portfolios, cost/effort constraints from user only when unsourced
- [ ] Map and read-only Data Explorer work; datasets side by side; raw/cleaned/derived traceable
- [ ] New portfolio does not reacquire unchanged source files

## G4 — product/documentation
- [ ] Home/landing/usage/architecture/docs, workspace, explorer, analysis, portfolio, data, activity, reports routes
- [ ] Earth globe optional; planetary geometry accurately labeled
- [ ] Optional AI calls bounded, consented and cacheable; no-AI mode passes

## G5 — release
- [ ] Browser and mobile/tablet navigation passes
- [ ] Public deployment loads without sign-in and has a stable worker/storage
- [ ] No credentials exposed, uploads protected or disabled
- [ ] Live report references real NASA/partner measurements
- [ ] Negative control, missingness, restart/retry and weight sensitivity tested
- [ ] Demo video, screenshots, source citation manifest and public repo ready

## G6 — submission
- [ ] Submission details and judging cutoff confirmed
- [ ] Short video and project links accessible without authentication
- [ ] AI use disclosure and data attribution included
- [ ] Successful receipt captured before deadline
