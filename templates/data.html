Data stages and their roles

scoring

Harmonized, normalized

Common ~11 km grid, each feature scaled 0–1 with percentiles shared by Earth, Mars and the Moon. The only data the similarity score is computed on.

explanation

Harmonized, physical

The same cells in physical units (m, degrees, K). Used to explain a match in real values, never to score it.

refinement

Processed

The body pipeline's native grid (Earth 0.01° ≈ 1 km). On Earth it drives the rover-slope filter and the exact test point.
