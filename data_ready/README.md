## Common feature schema (all `*_features.csv`)

| Column | Units | Meaning |
|---|---|---|
| latitude, longitude | degree | Cell centre (planetocentric, east-positive, -180..180) |
| elevation | m | Mean elevation above the body's reference surface (Earth geoid, Mars areoid, Moon 1737.4 km sphere) |
| slope | degree | Mean slope computed on the native DEM grid (baseline = native DEM pixel) |
| roughness | m | Standard deviation of native DEM elevations inside the cell |
| relief | m | Max - min native DEM elevation inside the cell |
| temperature_day | K | Daytime surface temperature (diurnal maximum, or observation near 10:30 local time on Earth) |
| temperature_night | K | Night-time surface temperature (diurnal minimum, or fixed night local time where flagged) |
| albedo | 1 | Surface albedo, 0-1 (product differs per body, see README) |
| thermal_inertia | J m-2 K-1 s-1/2 | Thermal inertia: resistance of the surface to temperature change (dust low, rock high) |
| mineral_index | wt% | Iron (Fe) abundance in the surface, weight percent |
| quality_flags | bitmask | See bits below |

Quality flag bits: `TEMP_DAY_ESTIMATED`=1, `TEMP_NIGHT_ESTIMATED`=2, `TEMP_FIXED_LOCAL_TIME`=4, `GAP_FILLED`=8, `ALBEDO_PROXY`=16, `COARSE_SOURCE`=32, `WATER`=64

`*_features_normalized.csv`: same columns, each feature scaled 0-1 with percentiles computed on
**all three bodies together** (`feature_normalization.json`), so values are directly comparable.

See `validation_report.md` for coverage, statistics and model checks.
